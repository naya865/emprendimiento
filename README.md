# N'ROSEN Studio

> "Porque sentirse bien también se viste"

Tienda virtual de ropa femenina: lencería, pijamas, enterizos, homewear, básicos y accesorios. La clienta navega el catálogo, elige talla, arma su bolsa de compras y envía el pedido por WhatsApp con un correo de confirmación.

**Ver la tienda publicada:** https://naya865.github.io/emprendimiento/

## Funcionalidades

- Catálogo de productos cargado desde una base de datos en la nube (Supabase).
- Filtro por categorías y buscador por nombre.
- Detalle de cada producto con galería de fotos y selección de talla.
- Bolsa de compras que se guarda en el navegador (localStorage).
- Perfil de clienta (nombre, correo y WhatsApp).
- Pedido por WhatsApp con resumen, total y método de pago (Nequi, Daviplata o efectivo).
- Correo de confirmación del pedido con EmailJS.
- Modo oscuro.
- Asistente virtual con respuestas sobre pagos, envíos y tallas.
- Panel de administradora para crear, editar y eliminar productos.
- Diseño responsive para computador, tablet y celular.

## Tecnologías

| Tecnología | Para qué la usamos |
| --- | --- |
| HTML5 y CSS3 | Estructura y estilos, con media queries para el diseño responsive |
| JavaScript | Lógica de la tienda |
| React 18 | Interfaz por componentes con useState y useEffect |
| Supabase | Base de datos en la nube para los productos |
| EmailJS | Correo de confirmación del pedido |
| WhatsApp | Envío del pedido a la tienda |
| GitHub Pages | Publicación del sitio en internet |
| Node.js, Express y MongoDB | Primera versión del backend con la API /api/productos |
